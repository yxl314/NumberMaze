# 数字迷宫 (number-maze)

一款基于 **特殊图连接拓扑** 的数字滑块游戏，使用 Qt6 开发。

把 1 到 15 的数字重新排回顺序、空格归位右下角即可通关。

## 与普通数字华容道的区别

这是本项目的核心特性，也是难度来源：

**普通华容道**使用 4×4 规则网格，只能上下左右推动。玩家凭空间直觉就能
判断"空格周围的格子可以动"。

**数字迷宫**的节点虽然也按 4×4 方阵摆放，但连接关系是项目专门设计的
拓扑，共 22 条边，其中包含多条**对角线连接**：

```
节点 1 (第0行第0列) 连到 节点 6 (第1行第1列)   ← 对角
节点 3 (第0行第2列) 连到 节点 8 (第1行第3列)   ← 对角
```

因此**不能靠位置直觉判断可移动性**，必须观察实际连线。全图的度数分布也
不均匀（4 个节点度为 2，12 个节点度为 3），进一步提高了难度。

界面默认画出全部连线，就是为此——不加辅助的话，玩家无从判断。

## 构建

需要 Qt6 (Widgets)、CMake 3.16+、支持 C++17 的编译器。

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/number-maze
```

## 玩法

- 点击**与空格相连**的数字，它会滑入空格
- 绿色高亮的节点表示当前可移动
- 虚线圆圈表示空格位置
- 把所有数字恢复成 `1..15` 顺序（空格在右下角）即通关

### 操作

| 操作 | 方式 |
|---|---|
| 移动数字 | 鼠标点击 |
| 悔棋 | 工具栏按钮 / `Ctrl+Z` |
| 重开本局 | 菜单「游戏」→「重开本局」/ `Ctrl+R` |
| 更换难度 | 菜单「游戏」→「新游戏」 |
| 显示/隐藏连线 | 工具栏「显示连线」 |
| 开关移动提示 | 工具栏「高亮可移动」 |

### 难度

| 难度 | 打乱步数 |
|---|---|
| 简单 | 20 |
| 普通 | 60 |
| 困难 | 150 |
| 专家 | 300 |

## 关于可解性

**任何局面都保证可解**，这是构造性保证，而非概率：

打乱不是随机排列，而是从已解状态出发执行**若干次合法移动**。因此沿着
这串移动的反方向走回去，必然回到已解状态。用一个简单的归纳就能证明：
每一步合法移动都可逆，所以整条路径可逆。

这也意味着本项目**不需要**标准华容道那套"逆序数 + 空格行号"的奇偶性
判据——那套判据只在"随机排列初始状态"时才需要。

另外，打乱不计入撤销历史，避免玩家用悔棋一路退回已解状态。

## 项目结构

```
number-maze/
├── CMakeLists.txt
├── src/
│   ├── main.cpp            程序入口
│   ├── graphmodel.h/.cpp   图结构与游戏逻辑（移动、打乱、撤销、胜利判定）
│   ├── puzzlewidget.h/.cpp 绘制与鼠标交互
│   └── gamewindow.h/.cpp   主窗口、菜单、状态栏、成绩记录
└── scripts/
    ├── screenshot.sh         虚拟显示下截图，验证渲染
    └── interaction-test.sh   模拟点击，验证交互链路
```

## 验证

项目带两个自动化验证脚本，用虚拟显示运行，无需真实桌面：

```bash
./scripts/screenshot.sh        # 截图确认渲染
./scripts/interaction-test.sh  # 模拟点击确认交互生效
```

`interaction-test.sh` 会发送多次真实鼠标点击，再对比前后截图，
若像素完全一致则判定交互失效。
